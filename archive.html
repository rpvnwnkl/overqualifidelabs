About this restoration

This archive combines the minimal GitHub website with the fuller local backup of OVERQUALIFIDE Labs. The skateboard project went through three rebrands, with a website created for each.

Original writing, artwork, photographs, and the press-release PDF are preserved. Historical contact and purchase destinations are recorded as text rather than current business services. The original Tumblr posts were not included in the backup.

The restoration adds readable text colors, responsive layouts, keyboard navigation, meaningful page titles, image descriptions, and text transcripts. Original scans and the PDF are retained; the HTML transcripts provide a more accessible reading option.

Old server configuration, logs, editor previews, and Jekyll demo content are not part of the public archive. The site needs only HTML and CSS; no JavaScript or server application is required.
